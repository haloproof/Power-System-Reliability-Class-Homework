# 发输电系统可靠性评估作业：IEEE RTS-79 系统与最优切负荷模型分析

---

## 1. IEEE RTS-79 系统介绍

IEEE Reliability Test System 1979 (RTS-79) 是电力系统可靠性研究中最经典的基准测试系统之一，旨在为不同的可靠性评估方法提供统一的比较平台。

### 1.1 系统基本组成
RTS-79 系统反映了典型的发输电网络特征，其核心结构如下：
* **节点 (Buses):** 共 24 个节点。其中 10 个为发电节点，17 个为负荷节点。
* **发电机组 (Generating Units):** 共 32 台机组，装机容量从 12MW 到 400MW 不等，全系统总装机容量为 **3405 MW**。
* **输电线路 (Transmission Lines):** 共 38 条支路（包含线路和5台联络变压器），涉及 138kV 和 230kV 两个电压等级。
* **负荷 (Load):** 系统年度峰值负荷为 **2850 MW**。

此外无功设备包括节点14同步调相机，节点6补偿电抗器。

### 1.2 关键可靠性参数
在可靠性评估中，每个元件的状态通常用随机过程描述，其核心参数包括：
* **强迫停运率 (Forced Outage Rate, FOR):** 元件处于不可用状态的概率，计算公式为：
  $$q = \frac{\lambda}{\lambda + \mu} = \frac{MTTR}{MTTF + MTTR}$$
* **故障率 ($\lambda$):** 单位时间内元件发生故障的平均次数（通常单位为：次/年）。
* **修复率 ($\mu$):** 单位时间内元件从故障中修复的平均次数。
* **元件容量 (Rating):** 发电机组的额定出力或输电线路的热稳定极限功率（MW）。

## 1. 节点导纳矩阵虚部 $\text{Im}\{\boldsymbol{Y}\}$ 的推导

节点导纳矩阵 $\boldsymbol{Y}$ 是描述电力网络拓扑和参数的核心矩阵，其元素为复数：$\boldsymbol{Y} = \boldsymbol{G} + j\boldsymbol{B_{bus}}$。

### 互导纳（非对角元素）
对于连接节点 $i$ 和 $j$ 的支路，其阻抗为 $z_{ij} = r_{ij} + jx_{ij}$，对应的支路导纳为：
$$y_{ij} = \frac{1}{r_{ij} + jx_{ij}} = \frac{r_{ij}}{r_{ij}^2 + x_{ij}^2} - j\frac{x_{ij}}{r_{ij}^2 + x_{ij}^2} = g_{ij} + jb_{ij}$$
根据节点导纳矩阵的构建规则，非对角元素 $Y_{ij} = -y_{ij}$。因此，其虚部为：
$$\text{Im}\{Y_{ij}\} = -b_{ij} = \frac{x_{ij}}{r_{ij}^2 + x_{ij}^2}$$

### 自导纳（对角元素）
节点 $i$ 的自导纳等于所有连接至该节点的支路导纳之和（包括对地支路 $y_{i0}$）：
$$Y_{ii} = \sum_{j \in i} y_{ij} + y_{i0}$$
其虚部为：
$$\text{Im}\{Y_{ii}\} = \sum_{j \in i} b_{ij} + b_{i0} = \sum_{j \in i} \left( \frac{-x_{ij}}{r_{ij}^2 + x_{ij}^2} \right) + b_{i0}$$
> **注意**：这里的 $b_{ij}$ 是支路电纳，通常为负值（感性），而 $b_{i0}$ 为对地充电电纳，通常为正值（容性）。

---

## 2. 直流潮流矩阵 $\boldsymbol{B}$ 的推导

直流潮流（DC Power Flow）是对交流潮流进行极度简化后的线性模型。其推导基于以下三个核心假设：
1.  **无功补偿充足/电压恒定**：所有节点电压幅值均为 $1.0$ p.u.。
2.  **相角差微小**：相邻节点间相角差 $\theta_{ij} = \theta_i - \theta_j$ 很小，满足 $\sin \theta_{ij} \approx \theta_{ij}, \cos \theta_{ij} \approx 1$。
3.  **忽略电阻**：线路电阻远小于电抗 ($r \ll x$)，认为线路无损耗，即 $r_{ij} \approx 0$。



### 功率方程推导
对于节点 $i$ 注入的有功功率，原始交流方程为：
$$P_i = V_i \sum_{j \in i} V_j (G_{ij} \cos \theta_{ij} + B_{ij} \sin \theta_{ij})$$
应用上述三个假设：
* $V_i = V_j = 1$
* $r_{ij} = 0 \implies G_{ij} = 0, B_{ij} = -1/x_{ij}$
* $\cos \theta_{ij} = 1, \sin \theta_{ij} = \theta_i - \theta_j$

代入后得到：
$$P_i \approx \sum_{j \in i} \frac{1}{x_{ij}} (\theta_i - \theta_j)$$
写成矩阵形式 $\boldsymbol{P} = \boldsymbol{B} \boldsymbol{\theta}$，其中矩阵 $\boldsymbol{B}$ 的元素定义为：
* **非对角元素**：$B_{ij} = -\frac{1}{x_{ij}}$
* **对角元素**：$B_{ii} = \sum_{j \in i} \frac{1}{x_{ij}}$

---

## 3. 两者之间的关系

节点导纳矩阵虚部 $\text{Im}\{\boldsymbol{Y}\}$ 与直流潮流矩阵 $\boldsymbol{B}$ 的关系可以概括为：**$\boldsymbol{B}$ 是 $\text{Im}\{\boldsymbol{Y}\}$ 在忽略电阻和对地支路后的负值。**

### 数学对应关系
若令 $\boldsymbol{B_{bus}} = \text{Im}\{\boldsymbol{Y}\}$，在 $r=0$ 且忽略对地电纳 $b_{i0}$ 的理想情况下：

| 元素位置 | 节点导纳矩阵虚部 $(B_{bus})$ | 直流潮流矩阵 $(B)$ | 关系 |
| :--- | :--- | :--- | :--- |
| **非对角** $(i,j)$ | $B_{bus, ij} = 1/x_{ij}$ | $B_{ij} = -1/x_{ij}$ | $B_{ij} = -B_{bus, ij}$ |
| **对角** $(i,i)$ | $B_{bus, ii} = \sum (-1/x_{ij})$ | $B_{ii} = \sum (1/x_{ij})$ | $B_{ii} = -B_{bus, ii}$ |

因此，在上述理想假设下：
$$\boldsymbol{B} = -\text{Im}\{\boldsymbol{Y}\}$$

### 核心差异点总结
1.  **电阻影响**：$\text{Im}\{\boldsymbol{Y}\}$ 考虑了电阻 $r$ 对虚部的影响（分母含有 $r^2$），而 $\boldsymbol{B}$ 强制令 $r=0$。
2.  **对地元素**：$\text{Im}\{\boldsymbol{Y}\}$ 包含线路对地电容、并联电抗器等信息；而标准直流潮流矩阵 $\boldsymbol{B}$ 通常只关注纵向支路，不计对地支路。
3.  **物理意义**：$\text{Im}\{\boldsymbol{Y}\}$ 是描述电流与电压复数关系的电路参数；$\boldsymbol{B}$ 是描述有功功率与节点相角线性关系的灵敏度参数。

这种关系也是**快速解耦潮流法（FDLF）**的基础，其中 $B'$ 矩阵正是借鉴了直流潮流矩阵的形式来简化雅可比矩阵的计算。
