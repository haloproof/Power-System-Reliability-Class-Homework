# 作业2-蒙特卡洛抽样

这篇文章的核心贡献是提供了具有解析解析形式的反函数 $\mathrm{CDF}^{-1}$ ，我们可以利用这一优势，设计一个**多时步风电出力曲线模拟**的作业。以下是为您优化后的作业设计：

------

### 1. 任务背景

本作业要求利用《Versatile distribution...》一文中提出的解析分布模型 ，结合蒙特卡洛抽样，模拟出多组与预测曲线相匹配的**真实出力可能场景**。

蒙特卡洛方法的优势？

### 2. 数学公式基础

作业核心将使用该论文提出的通用分布（Versatile Distribution）反函数 ：

$CDF(u|a,b,c) = c - \frac{1}{a} \ln\left(u^{-\frac{1}{b}} - 1\right)$

*(注：公式由原文 (4) 整理而来，其中 $u$ 是 $[0, 1]$ 之间的均匀分布随机数)*

### 3. 具体算例与步骤设计

**已知条件：**

- **预测曲线**：给定某风电场连续 2 个小时（8个点，每15分钟一个点）的预测出力值, 取2024年10月1日8:00-9:45 $P_{fore} = \{0.885, 0.868, 0.776, 0.668, 0.611, 0.594, 0.558, 0.452\}$。

- **参数查表**：学生需根据预测值，从作业1拟合的分布（**versatile_params.csv**）中查找对应的形状参数$(a, b, c)$。例如：当预测值为 $0.48$ 时，查第 13 号分箱的参数 。

**作业任务：**

1. **多场景生成（Scenario Generation）**：

   - 对每一个预测时间点，利用查到的$(a, b, c)$参数，进行 $N=1000$ 次蒙特卡洛抽样。
   - 将抽样结果连接起来，形成 1000 条可能的2 小时模拟出力曲线。

2. **指标计算（非系统可靠性指标，侧重统计特性）**：

   - **置信带验证**：利用论文中的解析公式 (5) 和 (6) 计算 90% 置信区间 ，并验证抽样生成的 1000 条曲线中，有多少比例的点落在了该解析区间内。

3. **收敛性讨论**：
- 增加抽样次数（如从 100 增加到 10,000），观察模拟曲线的**平均出力值**是否收敛于预测值，讨论样本量对模拟“极端场景”的影响。

### 4. 为什么这样布置更有意义？

- **关联性增强**：作业强制要求学生去查阅论文中的 Table I ，真正用活了“通用分布”能拟合不同预测区间、不同形状分布的特点。

- **体现“解析”优势**：由于论文给出了 closed-form（闭式解）的反函数 ，抽样过程不需要进行复杂的数值积分或迭代，计算效率极高，这正是该方法优于 Gaussian 或 Beta 分布的地方 。
